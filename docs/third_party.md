## Trained checkpoint

`checkpoint/walk_t4_*.pkl` are brax parameter pickles produced by `code/locomotion/train_walk.py`
in the MuJoCo Playground environment. They contain only weights and observation-normaliser
statistics trained here and are covered by this repository's LICENSE. Loading them with
`pickle` executes code paths of brax/jax; `analysis/evidence.py` reads them with a restricted
unpickler instead.
